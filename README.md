# BulkLot

Pokémon inventory sourcing network: AI agents and local human scouts.

## Run locally
Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Vercel / Netlify:** import the repo; no build step needed.

The site is a single self-contained HTML file. Fonts load from Google Fonts; `@solana/web3.js` and `tweetnacl` load from public CDNs.
